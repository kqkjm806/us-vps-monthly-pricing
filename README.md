## 下单前要知道的限制

**低价档不支持月付，这不是个案。** Akkocloud 标着 ¥24.9/月 的档位只能年付，同类情况在其他商家也常见：ByteVirt 的 512MB 款只能半年付、性能款 1GB 只能年付。看到"XX 元/月起"先确认那个"起"对应的是哪种计费周期。

**流量用超了会怎样，官网没写明白。** 套餐页标了每月流量额度，但没有公开说明超量后是限速、停机还是按量计费。这件事影响很大，下单前开工单问一句，比事后扯皮省事。作为参考，同价位段的商家普遍做法是超量后限速到 1Mbps 不停机，但那是别家的政策，不能套到这家头上。

**带宽分 300Mbps 和 500Mbps 两档。** 月付的 512MB 入门款是 300Mbps，季付、年付特惠和其他月付档是 500Mbps。日常建站感觉不出差别，做大文件分发或中转时会差一倍。

**512MB 别想装 Windows。** 这个配置只适合 Linux，官方也没有提供 Windows 模板的信息。

**退款条款官网没有明确写。** 这恰恰是月付存在的意义：只押一个月，不满意就不续，不需要走退款流程。反过来，年付之前最好确认清楚退款窗口，别默认有"几天无理由"。

**工单有时段。** 官方公告写的是服务时间中午 12 点到晚上 10 点，工作时间内提交的问题 24 小时内答复、48 小时内解决。机器半夜出问题，大概率要等到第二天。

**IP 不是永久保证。** 原生 IP 和流媒体解锁能力跟具体 IP 段有关，换 IP 后结果可能变。买之前把它当成"大概率可用"，不要当成合同条款。

## 几个常被问到的问题

**1 核 512MB 到底够不够？**
跑单个轻量服务够，跑 WordPress 紧。判断标准很简单：你的应用启动后常驻内存超过 350MB，就该上 1GB 档。数据库和 Web 服务挤在一台上时，512MB 是最容易在半夜被 OOM 杀掉进程的配置。

**流量超了会断网吗？**
官网没有公开说明处理方式，需要开工单确认。别默认"最多限速"。

**能退款吗？**
官网未见明确的退款条款。月付本身就是最稳的风控：一个月后不续费即可，不用走申请流程。要年付的话，先把退款政策问清楚再付款。

**支持支付宝吗？**
支持支付宝等国内常用付款方式，对没有双币信用卡的用户没有障碍。

**需要备案吗？**
海外机房不涉及 ICP 备案。内容合规责任仍然在使用者这边。
